# Истиклол Гурӯҳ — лендинг

Статический сайт: `index.html` + `js/` + `img/` + serverless-функция `api/lead.js` (заявки → Telegram).
Хостинг: Vercel (импорт этого репозитория). Переменные окружения: `TG_BOT_TOKEN`, `TG_CHAT_ID`.
Настройки контактов, метрики и адреса заявок — блок «НАСТРОЙКИ» в начале скрипта в `index.html`.
